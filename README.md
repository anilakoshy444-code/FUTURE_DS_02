# Customer Retention & Churn Analysis

## Internship
Future Interns — Data Science & Analytics

## Task
Task 2: Customer Retention & Churn Analysis

## Objective
Analyze customer data to understand churn patterns,
retention rates, and customer characteristics associated
with customer loss.

## Dataset
IBM Telco Customer Churn dataset.

The dataset includes customer demographics, services,
contract details, monthly charges, tenure, and churn status.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## Analysis Performed
- Data inspection and cleaning
- Churn rate and retention rate calculation
- Churn analysis by contract type
- Churn analysis by internet service
- Monthly charges analysis
- Customer tenure analysis
- Payment method analysis
- Historical revenue proxy analysis

## Visualizations
The project includes charts comparing churn across
customer contracts, internet services, payment methods,
monthly charges, and customer tenure.

## Recommendations
Recommendations will be based on the patterns identified
in the dataset and the results of the analysis.

## Conclusion
This project explores customer retention patterns and
identifies customer groups that may benefit from further
investigation and targeted retention strategies.
